# HTTPaaS — Servicio administrado de páginas y aplicaciones web

Parcial 3 de **Computación en la Nube 2026-2**. Es una mini nube local: una aplicación web en Go crea, a pedido del usuario, máquinas virtuales Apache a partir de un disco multiconexión de VirtualBox, las registra en un DNS Bind9 (`*.cloud.local`) y publica en ellas el `.zip` que sube el usuario.
